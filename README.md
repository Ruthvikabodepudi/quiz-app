🧠 Interactive Quiz App

An interactive Quiz Application developed using HTML, CSS, and JavaScript. The application presents a set of randomly selected questions for each attempt, allowing users to test their knowledge with real-time feedback and score tracking.

---

🚀 Features

- 🎯 Random selection of questions for each attempt
- 📝 Multiple-choice questions (MCQs)
- ✅ Instant answer validation (correct/wrong)
- 📊 Score tracking system
- 🔁 Restart quiz option
- 🎨 Clean and modern user interface

---

🛠️ Tech Stack

- HTML
- CSS
- JavaScript

---

📂 Project Structure

Quiz-App/
│── index.html

---

▶️ How to Run

1. Download or clone the repository
2. Open "index.html" in any web browser
3. Start answering the quiz questions
